# Vehicle Booking System

A comprehensive vehicle booking system with admin panel and user portal.

## Features
- Admin panel for managing vehicles, locations, and pricing
- User portal for booking vehicles
- Location-based pricing
- QR code verification system
- Real-time updates

## Technologies Used
- React
- JavaScript
- CSS
- Socket.io (for real-time updates)

## Installation
1. Run `npm install`
2. Start the development server with `npm run dev`
